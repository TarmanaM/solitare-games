# Project

Membuat webapp berupa permainan solitare. webapp ini simple.

# Stack

1. Nextjs
2. Prisma
3. Sqlite untuk db
4. MUI untuk Component FrameWork
5. Tanstack Server Manajemen State
6. Zustand Client Manajemen State

# Rule

1. Jangan pakai Typescirpt cukup Javascript saja
2. Setiap page sediakan bagian2 yang mana client side dan serverside (kalau belum perlu sesuatu dari server maka kosongkan saja)
3. Jika ada saran fitur atau sesuatu yang kurang maka tanyakan dulu dan berikan alasannya.
4. pisahkan atau pecah page dengan fitur
5. gunakan komponen kartu berupa text dan icon saja, belum perlu berupa gambar
6. buang komponen yang tidak perlu

# Additional

gunakan kalau ada fitur yang memerlukan

1. notistack untuk popup
2. SSE untuk notifikasi ke client browser atau keperluan logic backend ke client
